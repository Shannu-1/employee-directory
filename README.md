# Employee Directory Web Interface

## Overview

A modern, responsive employee directory web interface using HTML, CSS, and vanilla JavaScript.

---

## Features

- List employees with character details
- Add employee using a modal form
- Edit employee details with modal
- Delete employee with confirmation
- Search, filter, sort
- Pagination options
- Fully responsive design

---

## Setup & Run

1. Download or clone this project.
2. Open `index.html` directly in your browser — no backend or build tools needed.
3. Enjoy!
